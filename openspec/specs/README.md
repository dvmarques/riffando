# Especificações permanentes

As capacidades sincronizadas ficam em `<capacidade>/spec.md`. No fluxo padrão,
sync/archive ocorre na branch da PR antes do squash; essas specs chegam à base
de integração junto com a implementação.
A capacidade [ai-development-workflow](ai-development-workflow/spec.md) foi
sincronizada a partir da change [setup-ai-development](../changes/archive/2026-10-26-setup-ai-development/proposal.md),
arquivada com todas as tarefas concluídas antes do squash da PR #52.
Não há capacidades funcionais do app implementadas.

PRD descreve intenção de produto; specs descrevem contratos aceitos. Consulte
[as políticas de conclusão](../../AGENTS.md) antes de sincronizar ou arquivar.
